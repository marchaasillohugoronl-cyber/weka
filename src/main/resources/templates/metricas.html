Fórmulas aplicadas

Precisión = VP / (VP + FP)              →
Recall = VP / (VP + FN)              →
F1 = 2 × (Precisión × Recall) / (Precisión + Recall) →

Interpretación de resultados

Con datasets pequeños (<200 instancias) el accuracy puede variar entre ejecuciones. La cross-validation de 10 folds minimiza esta varianza usando todas las instancias tanto para entrenamiento como para evaluación.
